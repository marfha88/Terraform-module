# Consuming Modules via a GitHub App Token

When consuming modules from a private fork of this repository inside a CI pipeline, you can authenticate using a GitHub App instead of a personal access token.

## Prerequisites

1. A GitHub App installed on the repository with **Contents: Read** permissions.
2. The App ID and a private key stored as CI secrets.

## Generating a Token in GitHub Actions

```yaml
- name: Generate GitHub App token
  id: app-token
  uses: actions/create-github-app-token@v1
  with:
    app-id: ${{ secrets.APP_ID }}
    private-key: ${{ secrets.APP_PRIVATE_KEY }}

- name: Configure Git for Terraform
  run: |
    git config --global url."https://x-access-token:${{ steps.app-token.outputs.token }}@github.com/".insteadOf "https://github.com/"
```

## Terraform Source Reference

After configuring the Git credential helper, use the standard HTTPS source:

```hcl
module "storage_account" {
  source = "git::https://github.com/marfha88/Terraform-module.git//modules/terraform_azurerm_storage_account?ref=v1.0.0"
  # ...
}
```

## Notes

- Tokens generated by `actions/create-github-app-token` are short-lived (default 1 hour).
- Do not embed App private keys or tokens in Terraform source files.
- For public repositories (like this one) no token is required.
